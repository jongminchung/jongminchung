purpose: "같은 조건에서 변경의 효과를 나란히 비교합니다."
caution: "각 항목에 구체적인 제목을 붙이고 색상뿐 아니라 설명과 +/− 표시로 변경을 전달합니다."
---

<Comparison title="요청 키의 변경">
<ComparisonItem title="변경 전">

사용자 식별자만 사용하면 서로 다른 요청도 같은 요청으로 취급할 수 있습니다.

```ts title="before.ts"
const key = userId;
```

</ComparisonItem>
<ComparisonItem title="변경 후">

사용자와 요청 식별자를 함께 사용하면 요청 단위를 구분할 수 있습니다.

```ts title="after.ts"
const key = userId + ":" + requestId;
```

</ComparisonItem>
</Comparison>

<CodeExample>

```ts title="key-change.ts"
const key = userId; // [!code --]
const key = userId + ":" + requestId; // [!code ++]
```

</CodeExample>
