## 핵심 요약

- **`rke2spray`는 Kubespray의 Inventory·Playbook·Role 공개 형태를 RKE2 server·agent 수명주기로 변환함**
- **처음 사용하는 경우 시작 안내에서 설치 전 검사와 첫 클러스터 수렴까지 순서대로 진행함**
- **기존 Kubespray 사용자는 아키텍처와 호환성 문서에서 동일한 이름과 달라진 실행 의미를 먼저 확인해야 함**
- **운영 변경 전에는 Vault 검사, Inventory preflight와 클러스터 상태 확인이 필요함**
- **지원 범위의 최종 기준은 저장소의 machine-readable 호환성 계약과 support matrix임**

<Callout title="한 문장으로 이해하기" type="info">
  Kubespray 공개 API를 사용하고, 실행 엔진은 RKE2를 사용함
</Callout>

## 문서의 기준을 확인함

- **이 웹 문서는 운영자가 빠르게 탐색할 수 있도록 `rke2spray` 저장소 문서를 재구성한 안내 계층임**
- **변수와 지원 상태가 다르면 원본 저장소의 현재 release와 `docs/kubespray-api-compatibility.yml`을 우선함**
- **환경별 Inventory와 Vault ciphertext는 `rke2spray`가 아니라 이를 소비하는 환경 저장소가 소유함**
