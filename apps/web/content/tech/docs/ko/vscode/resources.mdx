## 자료를 사용하는 기준

확인일: 2026-09-06. 설정 키와 기능의 근거는 VS Code·도구 제작자의 공식 문서로 확인하고, 영상은 화면 흐름과 실습을 연결하는 자료로 사용합니다. 오래된 영상의 설치 명령과 확장을 그대로 복사하기보다 현재 프로젝트의 버전과 이 문서의 설정을 먼저 확인합니다.

## 원격 개발

- [Remote SSH](https://code.visualstudio.com/docs/remote/ssh): 원격 host·확장 설치·포트
- [WSL](https://code.visualstudio.com/docs/remote/wsl): Windows UI와 Linux 개발 환경
- [Dev Containers](https://code.visualstudio.com/docs/devcontainers/containers): toolchain·이미지·mount·확장

새 버전으로 갱신할 때는 문서 링크의 존재만 확인하지 않는다. 설정 키·확장 ID·runtime 조건·
실제 저장 결과·테스트 debug를 다시 검토하고 확인일을 갱신한다. 삭제된 영상을 검색 결과
페이지로 대체하기보다 현재 공식 자료를 연결하고 기존 영상의 상태를 기록한다.

## YAML·Shell 보충 자료

- [yamllint 설정](https://yamllint.readthedocs.io/en/stable/configuration.html): 규칙과 대상 파일을 확인합니다.
- [Red Hat YAML 확장](https://github.com/redhat-developer/vscode-yaml): 스키마와 편집기 진단을 연결합니다.
- [shfmt](https://github.com/mvdan/sh): Shell 방언과 포맷 옵션을 확인합니다.
- [ShellCheck](https://github.com/koalaman/shellcheck): 인용·변수·실행 규칙 진단을 읽습니다.
- [EditorConfig](https://editorconfig.org/): 파일별 들여쓰기와 텍스트 규칙을 확인합니다.

## 문서 갱신 기준

설정 키·확장 ID·runtime 조건이 바뀌면 본문 예제와 연결된 CLI 명령을 함께 검토합니다. 검증일은 실제 확인 범위와 함께 갱신하고, 재생되지 않는 영상은 상태를 확인한 뒤 현재 공식 자료로 대체합니다. 문서 원본은 이 Docs 영역에서 유지합니다.
