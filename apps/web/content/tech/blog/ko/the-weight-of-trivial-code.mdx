## 개요

await 없는 반환, 가변 기본 인자와 삼값 논리처럼 사소해 보이는 코드의 계약 비용을 분석합니다.

이 문서는 원본 자료의 시각적 순서와 상호작용을 보존해 각 개념을 단계별로 살펴본다.

## 출처와 범위

문서와 데모는 kciter 원본의 기술 용어, 코드 링크, 팔레트와 반응형 배치를 기준으로 이관했다.
