The Jamie icon is built around two precise ribbons surrounding an open center. The personal mark
represents openness and dependable structure.

## One source, multiple consumers

`@jongminchung/icon` owns the palette, geometry, approved variant, preview sizes, and registered app
output map. Apps must not copy SVG paths or treat a generated asset as a source.

| Consumer | Variant    | Use                                    |
| -------- | ---------- | -------------------------------------- |
| README   | `personal` | Header, favicon, and social preview    |
| Docs     | `personal` | Desktop and mobile navigation, favicon |

The tracked app SVG files exist because Next.js metadata requires physical files. They are
generated compatibility assets.

## Working with assets

```sh
pnpm icon:generate
pnpm icon:check
```

Run the generator only after changing the canonical package. Builds run the drift check and stop if
an app asset is missing or stale. The Playwright size sheet is a review record and changes only after
an intentional visual approval.

## Accessibility and new apps

Keep `JAMIE`, `Docs`, or the product name as the accessible label. Decorative marks use empty
alternative text. An app opts in by registering every required output in the central target map and
declaring the workspace dependency when importing the runtime API. Apps with a separate icon
pipeline do not need an exemption. Verify the icon at production sizes before updating a visual
snapshot.
