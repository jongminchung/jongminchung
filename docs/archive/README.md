# 완료 기록 보관함

완료된 TODO와 작업 기록을 보존한다. 연도는 보관 분류이며 원문에 없는 완료일을 추정하지 않는다.
현재 실행할 작업은 [이슈 인덱스](../issues/README.md)에서 확인한다.

- [2026년 Web Tech 완료 TODO](2026/todo.md): 카드 목록·썸네일·상세 페이지 적용 기록
- [2026년 완료 이슈](../issues/archive/2026/README.md): 기존 이슈의 결정과 검증 기록

과거 명령·측정값은 당시 근거로 유지하며 현재 실행 절차는 [기여 가이드](../CONTRIBUTING.md)를 따른다.
