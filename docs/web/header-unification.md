# Home·Tech·Invest 공용 헤더

- `EditorialHeader`가 세 사이트의 높이 64px, 좌우 여백 16px/32px, 탐색 전환점 768px을 소유함.
- `BrandWordmark`가 헤더 글자 20px과 Tech·Invest 접미사의 크기·배치를 소유함. Home 푸터의 15px 로고는 유지함.
- 모바일에서는 검색(Tech)·테마·메뉴 버튼을 제공하고, 기존 언어 컨트롤을 메뉴에 전달해 현재 경로와 언어 저장 동작을 유지함. 링크 선택·닫기·Escape와 초점 복귀는 공용 Sheet를 사용함.
- JavaScript 없는 환경에서는 헤더 아래에 목적지·문서 분류·언어 링크를 제공함.
- Home GitHub 헤더 링크는 1024px부터 표시하며 앵커 스크롤 여백은 80px임. 테마 Provider와 사이트별 저장 키는 유지함.

## 초기 JavaScript 예산

공용 Sheet 메뉴를 Home에 추가한 프로덕션 빌드에서 영문·한글 Home의 초기 JavaScript를 각각 측정함. 압축 전송은 약 227KB로 기존 230KB 상한 안이며, 압축 해제 크기는 약 717KB임. 따라서 `initial-transfer-budget.json`의 Home 두 경로에서 decoded 상한만 700,000 → 730,000 bytes로 조정함. Font·CSS·실제 JavaScript 전송 상한과 Tech·Invest의 예산은 유지함.

## 회귀 검증

`components/EditorialHeader.e2e.test.ts`에서 세 사이트·한영·라이트/다크와 320·390·767·768·1024·1440px을 조합해 높이·로고 크기·중앙 정렬·겹침·44px 터치 영역·가로 넘침을 검사함. 모바일 키보드·초점 복귀·언어 경로·JavaScript 없는 탐색·Home 앵커·사이트별 테마 유지도 검증함. Tech 검색과 기존 탐색은 사이트 E2E로 검증하고 세 사이트의 시각 기준 화면을 함께 관리함.

최종 검증: Web typecheck·루트 lint·프로덕션 build·단위 테스트 169개가 통과함. 기능 E2E 101개와 시각 회귀 14개를 통과했고, 세 사이트의 기준 화면 14개를 직접 검토해 갱신함. 초기 전송 예산 6개 경로와 `git diff --check`도 통과함.

## 후속 세부 점검

- 열린 메뉴의 버튼이 반응형 전환으로 숨겨지면 메뉴를 닫고 보이는 브랜드 링크로 초점을 옮김. 모바일 메뉴뿐 아니라 Tech 데스크톱 Docs 메뉴에도 적용함. `ResizeObserver`로 실제 버튼 표시 상태를 확인해 CSS의 768px 기준을 JavaScript에 중복하지 않음.
- 모바일 메뉴는 탐색 목록만 스크롤하고 제목·닫기 버튼은 유지함. 320×360px의 낮은 화면에서도 언어 링크와 닫기 버튼을 함께 사용할 수 있음.
- Tech Docs 드롭다운 항목의 최소 높이를 36px에서 44px로 맞춰 태블릿의 터치 조작을 보완함.
- 회귀 테스트는 화면 폭 왕복 전환 후 닫힘·초점·본문 스크롤 복구, 짧은 화면에서의 한영 메뉴 스크롤, Docs 항목의 터치 영역을 검사함.

후속 검증: 타입·린트·프로덕션 빌드와 관련 E2E 86개가 통과함. 기존 시각 기준 14개와 초기 전송 예산 6개 경로는 추가 갱신 없이 통과함. 낮은 화면에서 스크롤한 메뉴도 직접 확인함.
